# About The Brutalist

**The Brutalist** is a raw, typographically bold Jekyll theme inspired by newspaper front pages, Swiss punk posters, and brutalist web design.

## Design Principles

- **No decoration without purpose** — borders are structural, not decorative
- **Typography does the heavy lifting** — Bebas Neue headlines, Space Grotesk body
- **One accent color** — tabloid red (`#e8001a`), used sparingly for maximum impact
- **Inverse links** — links invert to white-on-black on hover; no color, just contrast

## Configuration

```yaml
brutalist:
  invert: false        # true = white-on-black mode
  rule_weight: "heavy" # light | medium | heavy
  uppercase: true      # uppercase all headings
```
